# Little Surprise ✨ - Interactive Moments for Someone You Love

A 100% free, private, and interactive digital surprise creator. Create personalized interactive birthday cards, romantic proposals, apologies, and love surprises. Send with a private link!

Zero subscriptions, zero paywalls, zero database costs. Everything runs in the browser and shares instantly via private links.

---

## ✨ All 4 Experiences Included

### 1. 🎂 Birthday Card
- **Features**: Interactive 3D cake with blowable flickering candle, pop-the-balloon secret compliments mini-game, polaroid photo memories (with side arrows & photo counter), customizable color themes (Rose, Golden Sunshine, Lavender Dream, Ocean Breeze), and a wax-sealed letter with party poppers finale.
- **Badge**: 🔥 Bestseller

### 2. 💙 Apology Card
- **Features**: For apologies that need more care than a text message. Sincere honest reflection cards with gentle piano music, treasured photo memories, heartfelt handwritten letter sealed with a heart wax stamp, and an interactive "Will you forgive me?" with virtual hug & WhatsApp patch-up button.
- **Badge**: ✨ New

### 3. 💍 Romantic Proposal
- **Features**: Drifting rose petals, romantic melody, "Our Journey" photo timeline, velvet jewelry box that opens with a sparkling diamond ring, and the playful runaway "No" button that dodges the cursor with cute messages leaving only the big glowing "YES! ❤️".
- **Badge**: ★ Most Popular

### 4. 💕 Show Your Love
- **Features**: Show them exactly why you love them. Interactive scratch/tap cards revealing personal reasons, photo gallery, sealed love letter, and the interactive "Love Meter" that charges from 100% to INFINITY ∞ % with heart explosion celebration.
- **Badge**: 🚀 Just Launched

## 🎵 Background Music & Audio
- **Curated Melodies**: Happy Birthday Music Box, Romantic Piano, Peaceful Canon, Warm Joy, Delicate Chimes, Peaceful Acoustic.
- **Custom Audio Upload**: Upload `.mp3` or `.wav` files directly or paste an audio URL.
- **One-Touch Autoplay**: Web Audio API with automatic interaction unlocking.

---

## 🚀 How to Run Locally

```bash
# Install dependencies
npm install

# Start Vite local development server
npm run dev

# Build for production
npm run build
```

---

## 📦 Tech Stack
- **Framework**: React 18, Vite
- **Styling**: Tailwind CSS, Lucide React Icons
- **Effects**: canvas-confetti, Web Audio API synthesizer
- **Compression**: lz-string
